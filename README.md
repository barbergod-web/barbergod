# Barber God

Sitio web de Barber God, barbería en Las Condes, Santiago (Chile).

- Página estática: abre `index.html` en el navegador.
- Fotos y logo en `img/`.
- Si editas un `<script>` de `index.html`, ejecuta `python csp-hash.py` para actualizar la Content-Security-Policy.
- `_headers` contiene las cabeceras de seguridad para publicar en Netlify.
